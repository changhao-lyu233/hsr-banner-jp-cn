# data/manual：人工编码表

这里是作者手工编码或核定的表，分析脚本只读取、不改动。资料检索和整理有 AI 辅助（Gemini、千问、Claude），最终编码由作者确定。

## 文件一览
| 文件 | 一行是什么 | 怎么来的 | 分析里怎么用 |
| --- | --- | --- | --- |
| `character_coding.csv` | 一个限定五星角色（58 个） | 带"(自动)"的列来自 B 站 wiki；其余由作者填 | 强度、定位、主推、SP、同位体、性别；日语 CV 用来连 `va_final.csv` |
| `story_scoring.xlsx` | 一个人在一段剧情里的出场 | AI 整理出场，作者打"高光加成 0–3" | 算剧情铺垫分和当期分（规则见下） |
| `va_final.csv` | 一位声优（日配、国配共 103 人） | Claude、Gemini、千问分别判断，作者裁定 | "主分析编码"列：1 = A 档，0 = B 或 C 档 |
| `buffs.csv` | 一个被加强的角色（3 批 10 人） | Gemini 查加强内容，按卡池表核对复刻日期，作者填加强前后强度 | 只做标记和描述 |

## character_coding.csv
- 所有判断都按"该角色首次 UP 时"。
- 强度：0/1/2 = T0/T1/T2。T0 = 当期环境顶级、几乎推荐必抽；T1 = 强但非必需；T2 = 一般或偏弱。只看当时环境，不看后来卖得怎样。
- 定位：C、主C/副C 算主C；辅助、生存、副C/辅助算非主C。
- 是否主推：1 = 官方当期主推（游戏内制作和游戏外宣发投入明显高于一般角色）。"主推"的说法是后来才形成的，1.x 的丹恒·饮月、镜流是事后归类：当时游戏内外投入和售卖预期都明显高于同期角色。
- SP 形态：1 = 老角色的新形态。
- 同位体：只保留明确的 9 个（1 = 明确），"同位体原型"写原型是谁。

## story_scoring.xlsx
- "重点剧情打分"页：主线、开拓续闻、同行任务、3.8 终末任务里，角色作为主角之一或重要配角的出场。
- "其他线索"页：少量出场、仅提及、活动剧情、冒险任务、模拟宇宙。只给有明显加成的行打分，**空着的一律按 1 分**。
- "开池前官方PV"页：只作参考，不进入计算。
- 高光加成：1 = 基准分（只是露脸）；0 = 观感差、玩家不喜欢；2 = 塑造不错，明显加成；3 = 塑造非常好，容易产生厨力。角色在自己的重点剧情里拿 2–3 分是常态，只拿 1 分说明剧情有争议。
- "编号"列是合并用的键。

由打分算剧情变量（`scripts/build_analysis_table.py` 照此实现）：
- 同一个人的不同形态合并：本体的行同时算给本体和 SP（丹恒·饮月、丹恒·腾荒 → 丹恒；大黑塔 → 黑塔；长夜月 → 三月七；忘归人 → 停云；姬子·启行 → 姬子；火花 → 花火；知更鸟·晴歌 → 知更鸟；砂金·戏浪 → 砂金；银狼LV.999 → 银狼；千冶·刃 → 刃）。
- 铺垫分 = 该角色首次 UP 版本**之前**所有行（两页都算）的最高分；一行都没有记 0。
- 当期分 = UP 那个版本里的最高分。例外：版本中途才上线的剧情不算给同版本上半的角色（目前只有 1.2 的刃和同行任务「陌生女人的来信」，2023-08-09 上线）。
- 稳健性：累计口径 = UP 前 2 分以上的行数；远近口径 = 最高分那一行距 UP 隔 10 个版本以上的减 1。

## va_final.csv
- 日配：按角色上线时声优在日本的人气分 A（一线）/ B（中坚）/ C（其他）。
- 国配：按综合分定档，人气判断为基础、米哈游作品出演只做加权（千问 0–2 + Gemini 0–1 + 原神或绝区零出演 +1、只有崩坏3 +0.5；≥3 为 A，≥1 为 B，其余 C）。作者裁定优先，见"作者裁定"列。
- 档位人数：日配 A 29 / B 21 / C 2；国配 A 26 / B 22 / C 3。A 档偏宽，比较的实际是"主流配置对少数配置"。
- "日配：偶像/乐队企划成员"列用于稳健性检验。

## buffs.csv
- 加强前强度：流萤、藿藿为 T1，其他为 T2；加强后强度由作者填。加强后档位不变说明加强力度小。
- 只做标记和描述，不做检验（样本太少）。
